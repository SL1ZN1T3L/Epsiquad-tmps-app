Android-клиент для [tmps.epsiquad.com](https://tmps.epsiquad.com) - временных файловых хранилищ. Создайте хранилище, загрузите файлы и отправьте короткую ссылку. Когда срок истечёт, всё удалится само.

## Возможности

- Вход по логину и паролю или через Telegram, повторный вход по отпечатку
- Список хранилищ с таймером, занятым местом и режимом доступа
- Живое обновление: файл, загруженный или удалённый на сайте, появляется в приложении сам
- Создание хранилища: выбор тарифа и срока, тарифы приходят с сервера
- Загрузка файлов частями с паузой, продолжением и повтором после обрыва связи
- Просмотр файлов, скачивание по одному и всего архивом - в «Загрузки», с прогрессом и докачкой
- Счётчики просмотров и скачиваний для владельца
- Продление срока, смена тарифа в обе стороны, смена режима доступа и ссылки
- Список устройств с активным входом и отзыв любого из них
- Обновление из приложения: APK под вашу архитектуру, сверка SHA-256, запуск установщика

## Требования

- Android 8.0 и новее
- Аккаунт на tmps.epsiquad.com: создаётся на сайте или в боте, в приложении только вход

## 📦 Установка

1. Откройте [страницу релизов](https://github.com/SL1ZN1T3L/Epsiquad-tmps-app/releases) и скачайте APK.
   - `app-arm64-v8a-release.apk` - для большинства современных телефонов
   - `app-release.apk` - универсальный, весит больше, подойдёт любому устройству
2. Разрешите установку из неизвестных источников. Android спросит об этом сам при открытии файла, либо: Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → ваш браузер или файловый менеджер.
3. Откройте скачанный APK и подтвердите установку.
4. Запустите приложение и войдите.

Проверить, что файл не подменили: рядом с каждым APK в релизе лежит файл `.sha256`.

```bash
sha256sum -c app-release.apk.sha256
```

### Первый вход

- **Логин и пароль** - те же, что на сайте.
- **Telegram** - кнопка откроет бота, нажмите «Подтвердить», приложение войдёт само.

После входа в настройках можно включить вход по отпечатку: токен доступа останется в защищённом хранилище телефона, а открыть приложение без биометрии не получится.

### Если что-то не работает

- **«Нет связи с сервером»** - проверьте интернет и что открывается tmps.epsiquad.com в браузере.
- **«Нужно обновить приложение»** - сервер перестал поддерживать вашу версию, скачайте свежий APK из релизов.
- **Не приходит подтверждение из Telegram** - проверьте, что бот не заблокирован, и начните вход заново.
- **Потерян телефон** - зайдите на сайт, вкладка Аккаунт → Устройства → отключить. Вход с того телефона перестанет работать сразу.

### Подпись релиза

Подпись берётся из `android/key.properties`, файл в репозиторий не попадает:

```properties
storeFile=upload-keystore.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

Если файла нет, релизная сборка подписывается отладочным ключом - так собирается локально, но раздавать такой APK нельзя.

Сборка в CI берёт ключ из секретов репозитория: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. Релиз публикуется при пуше тега вида `v1.0.0`.

### Как устроен доступ

Приложение не хранит никаких общих секретов - в открытом репозитории их просто нет. После входа сервер выдаёт пару токенов: короткий access на 15 минут и refresh на 90 дней. Refresh лежит в Keystore, ротируется при каждом обновлении, и если старый токен попробуют использовать повторно, сервер отзовёт устройство целиком.

Файлы загружаются и скачиваются не через основной API, а прямо в контейнер хранилища. Ключ на конкретное хранилище выдаёт `POST /api/v1/storages/{code}/token`, живёт он сутки и уходит в заголовке `X-Tmps-Owner` - в том числе при скачивании, поэтому в ссылках и в истории браузера он не оседает.

Тарифы, лимиты и размер части файла приложение не хардкодит - всё приходит из `GET /api/v1/config` после входа. Поэтому изменения на сервере не требуют обновления приложения.

Полная спецификация API: `https://tmps.epsiquad.com/api/v1/openapi.json`.
